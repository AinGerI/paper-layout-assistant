# Markdown 输入约定

这是可复现的论文输入子集。以下代码围栏只用于这份说明展示；实际输入Markdown中的公式不要加代码围栏。AI 应先生成符合此约定的文件，再转换。任意网页 Markdown 应先规范化，不直接假设脚本支持所有扩展。

## 标题与正文

- `# 论文标题` → Word Title（文档标题，不参与章号）。
- `## 第一章 研究背景` 或 `## 1 研究背景` → 真正的 Word Heading 1。
- `### 1.1 数据` → Heading 2；`#### 1.1.1 指标` → Heading 3。
- 普通段落用空行分隔。段落内部换行合并为空格，不用换行制造首行缩进。
- 按章编号时，一级标题必须有明确数字，章号互不重复且递增。可以是第一、第四、第五章；宏按实际章号读取，不当作第一、第二、第三章。插入第三章应放在第四章之前。
- 无编号的摘要、参考文献不作为有编号章节。`## 参考文献` 后按参考文献角色排版。

## 行内公式

正文示例：系统功率为 `\(P_t\)`，时段电量为 `\(E_t=P_t\Delta t\)`。

转换后 Word 中行内代码使用 `$...$` 包裹并带独立 PWD_EQ_ 书签。货币在正文写“美元”或“USD”，避免孤立美元符号被误认为公式开头。公式分隔符不能跨 Word 段落；不得嵌套两层外部分隔符。

## 带编号的行间公式

独立块，块前后空一行：

```latex
\begin{equation}
E=mc^2
\end{equation}
```

转换器把整个块压成一个 Word 段落。公式内部 TeX 换行 `\\` 保留。不要自己写 `(3-1)`、`\label` 或 `\tag` 来固定结果；编号交给 MathType。宏不把行内公式强行改成带编号行间公式。

## 无编号行间公式

```latex
\[
\nabla\cdot\mathbf{B}=0
\]
```

无编号意图保留。需要编号时改用 equation 外层。历史稿中 `\[...\tag{n}\]` 若由转换器兼容接收，n 只表示需要编号，旧数字不作为最终编号；新稿统一用 equation。

## 多行等式、不等式混合

优先整行单列，减少为了对齐造成的横向大空隙：

```latex
\begin{equation}
\left\{\begin{array}{l}
x_1+x_2=1\\
2x_1-x_2\leq 3\\
x_1\geq 0,\quad x_2\geq 0
\end{array}\right.
\end{equation}
```

一组多行约束对应一个编号。`array{l}` 是新写公式的可用默认形式，不应自动改写用户已有的矩阵列数、对齐或数学结构。明确有对齐需要时可用多列 array。未知命令、超宽长式和复杂物理表达式要在 Windows 中目视复核。

## 表格与图片

用矩形 HTML 表格，每行同样多列，不用合并单元格。单元格内可写 `\(...\)` 行内公式。例：

```html
<table><tr><th>量</th><th>表达式</th></tr><tr><td>电量</td><td>\(E=P\Delta t\)</td></tr></table>
```

整张表作为一个块，不在表格代码中插入空白段落。编号行间公式应放在正文独立段落；表格单元格宜用行内公式，避免把表格当成公式编号布局工具。

图片独占一块：`![日负荷曲线](images/load.png)`；图片路径相对 Markdown，真实图片必须随源文件交付。保持比例、受 profile 最大宽高限制。

表题写在表前，图题紧邻图片前或后，各自一段，如“表 1 能耗指标”“图 1 日负荷曲线”。题注居中、正文同字体字号、段前段后 6 磅、零首行缩进。当前转换器按“邻接图表＋图/表数字前缀”识别题注，完整正文若也以“图1/表1”开头且紧邻图表，同样可能被识别为题注；句子完整性不会自动消除歧义。生成前明确正文/题注语义，转换后核对coverage.json的captions列表和实际段落样式。忠实转换时不为绕过识别改写文字，按 [题注纠偏步骤](formatting.md) 局部恢复正文样式。

列表、脚注、引文语法、超链接、代码围栏和复杂 HTML 并非通用论文转换器承诺支持的输入；先规范化为明确结构，或扩展解析与回归后再使用，不可静默丢失格式/内容。

## 与固定宏一致的输入检查

交付前检查公式花括号成对、无嵌套外层分隔符、无未闭合公式。公式代码不得含未转义的百分号注释；从LaTeX来源整理时，在原始换行仍保留的阶段识别并移除真正的注释，百分数用\%保留。不要先把行拼接再删注释，以免误删后续公式。

固定宏不接受\tag、\label、\nonumber、\notag。新稿需要有无编号时用本页规定的外层环境表达；从旧稿迁移前先核对原编号和正文引用，不能去掉指令后留下错误的引用。历史\[...\tag{n}\]只有前文说明的兼容含义。当前转换器没有完整复刻宏的所有输入检查，生成成功仍需做此项源码核对。


## 普通连接文字与公式边界

`\(CO_2\&\mathrm{AP}\)` 曾在用户 Windows MathType 7 实测显示红色 `\&`。这属于本工作流兼容风险，不代表 TeX 语法本身不合法。

这类连接应写成 `\(CO_2\) & AP`：公式只包含需要数学排版的内容。转换器拒绝行内公式中的字面 `\&` 并给出改写提示，不自动修改数学含义。若 `\&` 确为数学表达的一部分，先核实目标端可用表示，再修改该输入，不能盲删反斜杠。多行 array/aligned 中的原始 `&` 是对齐符，必须保留；不能全局替换所有 `&`。
