# Word 论文排版工作区

以后只需要使用前三个文件夹，不用查看程序文件。

| 文件夹 | 放什么 |
| --- | --- |
| **01 模板库** | 按华为杯、统计建模等分类保存模板、参考论文、格式要求和排版配置。 |
| **02 待排版论文** | 放你要排版的 Word 原稿。 |
| **03 排版结果** | 我生成的排版副本和中文检查报告。 |
| **90 维护备份** | 安装包、源码和必要的历史记录，日常不用打开。 |

## 如何添加模板

“模板库”已经建好 **华为杯** 和 **统计建模** 两类。每类有三个文件夹：

- **01 模板与参考论文**：放 Word 模板或已有论文。请在文件名中区分“官方模板”和“参考论文”。
- **02 格式要求**：放 PDF、Word 或文字格式说明。直接在聊天里发要求也可以。
- **03 排版配置**：由我生成和维护，平时不用手动修改。配置是给程序读取的格式规则，不是论文。

以后有新比赛，直接在“01 模板库”里新增对应名称即可。同一比赛不同年份或版本，建议再分文件夹，避免混用。

## 如何使用

把论文放进“02 待排版论文”，然后告诉我：

> 使用 word-format，按模板库里的“华为杯”要求排版我的论文，保留原稿，把副本和中文检查报告放到“03 排版结果”。

也可以说：

> 使用“统计建模”模板，先检查格式要求，再排版这份 Word。
