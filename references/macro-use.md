# 正式通用宏：安装一次，按稿复用

## 唯一正式文件与入口

本包固定使用用户已经在Windows测试后确认可用的独立入口版。文件字节、模块名和公开入口不作美化改名；名称里的Check是兼容保留，不表示需要每次重新测试。

| 用途 | 入口 |
|---|---|
| 整篇及增量处理（默认） | PWD_Run133_Check |
| 单条正反切换，可绑定Alt+/ | PWD_One133_Check |
| 单独同步章节编号 | PWD_Chapters133_Check |
| 单独修复公式段落网格 | PWD_Grid133_Check |

文件：`assets/PWDMathType133Check.bas`；模块：`PWDMathType133Check`；窗口标题：`PWD MathType 1.3.3 CHECK`。身份与冻结说明见包根release.json。不要从其他旧版本复制同名函数拼装新宏。

## 初次安装

目标环境是Windows桌面Word和MathType 7 Word插件，先确认MathType自带插公式功能可用。

1. Word按Alt+F11，在Normal工程导入本包BAS。这样不同DOCX可调用同一宏，无需把宏嵌进每份文档。
2. 若该模块已经安装并正常使用，不重复导入；若出现末尾“1”，先检查是否已有副本。
3. Alt+F8明确选择PWD_Run133_Check。不要用旧宏入口或仍绑定旧版的快捷键代替。
4. 如需Alt+/：文件→选项→自定义功能区→键盘快捷键“自定义”→宏→PWD_One133_Check，输入Alt+/并指定，保存到Normal。先查看该键原来绑定什么；绑定会替换该键原用途。
5. 保存Normal模板修改，按本机正常信任设置启用宏。不要全局关闭Office安全设置。

用户已安装这一份时无需再安装。将来确有代码更新，应先导出当前模块，再在用户明确更新范围内替换该模块；不删除MathType自带模块，不清空整个Normal模板。

## 一次主流程

1. 选择是否备份。“是”先保存当前编辑，再实际复制到文档旁“公式备份”目录；成功路径显示在状态栏。“否”直接处理；“取消”退出。新文档在需要保存时选择文件名。
2. MathType窗口设置全文连续编号，或含章号的1.1/1-1形式。章号来自真正的Word一级标题及其明确数字。
3. 宏验证旧标记，发现新代码，转换新公式；已有MathType对象保留。同步章号/顺序，取消公式段落的两项网格设置，检查文字和非公式对象。
4. 最后一个窗口合并显示本次成功转换条数、正文MathType总数及处理耗时，并询问是否保存到当前文件。选择不保存时保持未保存状态，之后Ctrl+S或关闭时由Word正常询问。

宏不会另建一个结果Word。正常对象缩放、图片尺寸调整及“已保存成功”不单独弹窗；真实转换错误、内容变化、网格未修正或超宽需要检查时才提示。耗时不计主备份选择/复制、主编号设置及最后保存确认的时间，不是某个提速倍数的证明。

## 增量编辑

| 操作 | 做法 | 核对 |
|---|---|---|
| 补一句带行内公式的话 | 粘贴规范的`\(...\)`或`$...$`，运行主入口 | 只新增这条，原有对象保留 |
| 加编号公式 | equation外层代码独占一个Word段落 | 新式有原生编号，后续顺序更新 |
| 第一、四、五章中插入第三章 | 在第四章之前插入“标题1”段落，明确写第三章，再加内容 | 新章从3-1起，原四/五章不变成第二/三章 |
| 改已有公式 | 双击MathType对象编辑，或完整替换为规范代码再运行 | 没有旧对象或重复编号残留 |
| 删公式 | 删除该对象及所属编号，保留周围正文，再运行 | 后续编号连续 |
| 移动章节 | 标题和内容一起移动，修正章号，使顺序递增 | 公式服从当前位置的章号 |
| 不改内容再运行 | 再用同一主入口 | 新增0，数量和编号保持 |

粘贴已编译的整章可能带重复书签、旧章标记或外来样式。优先使用未编译的规范片段；来源不明的章节标记不能静默删除。正文格式由生成脚本/目标样式控制，宏不会自动重排任意粘贴文本。

## 单条快捷键与辅助入口

PWD_One133_Check是双向切换：已有MathType对象转回TeX；代码转成对象。单条代码支持`$...$`、`\[...\]`及equation/equation*外层；`\(...\)`使用主入口处理。先写好代码，再将光标置于代码内或选中整条公式后按Alt+/。

主入口负责备份、编号设置、批量检查和最终保存确认；辅助入口不是完整主流程，不自动提供同样的备份/保存提示。需要批量处理时不要逐条按快捷键代替主入口。

## 编号与普通Word域保护

编号使用MathType原生字段，结合一级标题设置章号和公式计数器，不是写死的括号数字。普通手写“见式(3)”仍为文本；自动引用需用MathType引用功能建立。

MathType插件内部可能更新所有story中的字段。正式宏在主入口、单条和章节入口调用插件前临时锁定非MathType域，成功或失败后恢复原状态；原本锁定的域不会被解锁。可识别的MathType引用须指向MTPlaceRef代码内部、仅包含原生计数字段的编号片段；包含正文的整段书签不获得更新豁免。锁恢复失败会明确报错。

正文完整性检查失败会显示第一处“变化前／变化后”。整个批次不是一次原子撤销：失败单条会尝试回滚，之前成功转换可能仍留在当前稿中，主流程不自动保存；恢复整篇应使用运行前备份。不要用关闭完整性检查、删除域或解除链接来绕过报错。

重新安装到不同电脑或更换Word/MathType版本时，用检查稿验证普通域、表格公式、章号、重复运行及保存。检查普通域要记录运行前实际值，不能把Word打开时已刷新的结果误算为宏改动。用户本次成功反馈是这一版本的运行依据，不代表所有外部稿件或所有版本组合已被测试。
